Users:

when users are asked to create an account in the sign up page, they are asked for the following:

email
phone number (optional)
first name
last name
date of birth
password
confirm password

a captcha will then pop up to prove that they are human.

to sign in, users sign in using their account email and password.

Name (first, last)
email
comments/inquiry

this can then be reviewed by the owner/admin in the admin view
