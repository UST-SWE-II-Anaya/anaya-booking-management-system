Users view:

users with accounts can do the following:

1. check their current bookings
2. check their past bookings
3. cancel their bookings (if within the cancellation policy)
4. view their profile information
5. edit their profile information
6. add/change their profile picture
7. change their password
8. log out

The appointment booking manager page where users can check their current bookings have appointment cards. The appointment cards have the following details:

    Appointment ID
    Appointment Date
    Appointment Time (Starting)
    Appointment Duration
    Appointment Service/s
    Appointment Status (Upcoming, Finished, Cancelled, No Show)
    Downpayment Status (Pending, Paid)
    Downpayment Total
    Balance (This is the balance of the whole booking. The downpayment total is deducted in this amount.)
    Time left to pay (This is the time left to pay the downpayment. If the downpayment is not paid within this time, the reservation will be cancelled by the system. This is only applicable for pending downpayments)
    Two buttons: 
        1. Pay Downpayment (if they decided to book first without paying the downpayment)
        2. Cancel Reservation (if they decided to cancel the reservation)

Booking page:
    Users can select a service and a date and time to book an appointment.

    There are service categories and the services themselves. For example:

    Package
        She Nailed It
            Package 1
            Package 2
            Package 3
            Package 4
            etc...
    Nail Care
        Classic Manicure
        Classic Pedicure
        Gel Polish Change
        Gel Manicure
        Gel Pedicure
        etc...

    The chosen packages/services of the users will be displayed in booking summary card. The booking summary card has the following details:

        All the services currently in the cart
        Total Price
        Downpayment (10% of the Total Price)
        Total Duration (estimated)

    There is a list of all the services available in the system. This service card has the following details:

        Name of the service/package
        Estimated Duration
        Price
        Description
        Add to Cart button

    After choosing the services and/or packages, the user will be directed to the Select A Professional page. The user can select a professional by choosing a professional from the list of professionals. They can choose from the following options:

        1. Any available professional
        2. Any female professional
        3. Any male professional
        4. A specific professional

    After selecting a professional, the user will be directed to the Select A Date and Time page. The user can select a date and time to book an appointment. The user can select a date and time by choosing a date and time from the calendar. The calendar will display the available dates and times for the selected professional. The calendar will default to the current date. After choosing a date, under the dates of the month, Available Times for [Date] will appear. This will display times from 9:00 AM to 7:30 PM with 30 minute intervals. The times displayed will be the available times for the selected professional. If the selected professional is not available at a certain time, it will not be grayed out.
