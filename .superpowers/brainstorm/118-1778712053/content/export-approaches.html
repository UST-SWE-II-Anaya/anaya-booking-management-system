Export Feature — 3 Approaches

How should the export button work? Pick the approach that feels right.

A

Single Export Button

One "Export CSV" button in the toolbar. Always exports all records matching the current status filter and search — all pages, not just the visible one. Fast and frictionless.

Pros

  • Zero extra clicks
  • Predictable behavior

Cons

  • No date range option
  • Less flexible for reports
B

Export Button + Dropdown Recommended

A split button: clicking "Export CSV" immediately exports the current view. A small chevron opens a dropdown with a "Custom export…" option that launches a modal with date range + status controls.

Pros

  • Fast path for common case
  • Date range available when needed

Cons

  • Split button slightly less obvious
C

Always-Modal Export

One "Export" button always opens a modal. The modal pre-fills from the current filter but lets the admin change status, date range, and choose which columns to include before downloading.
