Service function: exportBookings

Lives in bookingService.js. Accepts { status, dateFrom, dateTo } — all optional. Fetches all matching rows (no pagination), returns an array. CSV generation happens client-side in the component using a plain string builder — no external library needed.

exportBookings({ status?, dateFrom?, dateTo? })
→ filters bookings by appointment_date range and/or status
→ selects same BOOKING_SELECT fields as getBookings
→ no .range() call — fetches all matching rows
→ returns raw data array (caller builds CSV)

CSV generation (client-side)

A small utility function inside the modal component converts the data array to a CSV string, then triggers a browser download via a temporary <a> element. No npm packages needed.

columns: Ref ID, Customer Name, Email, Phone, Date, Time,
         Services, Subtotal, Downpayment, Remaining Balance,
         Booking Status, Payment Status, Staff, Notes, Created At

filename: bookings-export-YYYY-MM-DD.csv

Data flow

1. Admin clicks "↓ Export CSV" → calls exportBookings({ status, search: undefined }) directly, downloads file
2. Admin clicks "▾" → Custom export…" → opens ExportBookingsModal
3. Admin sets date range + status → clicks Download → modal calls exportBookings({ status, dateFrom, dateTo }), builds CSV, triggers download, closes modal
